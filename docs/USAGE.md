# 使用 AI 桌宠

## 常用操作

- 单击本体：额度 → 语录 → 下一句；Claude 直接显示语录。
- 连续点击：默认第三次开始随机换表情，设置可选第 1～10 次。每只宠物独立保存。
- 按住 DS：摸头。DS 的十种随机表情保留两版微笑，不包含害羞。
- 拖动本体：在宿主窗口内调整位置，或在桌面模式自由拖动。
- 右键本体：设置、聊天速度、退出。所有气泡都是显示用途，可以点击穿透。
- 完成提醒出现时单击本体：返回对应宿主。Codex 仅在对话 ID、数据库索引和真实记录路径一致时打开具体对话，否则回到 App。其他宿主保守回到 App。

## 设置

顶部四个标签切换当前设置对象。修改第三次随机等设置只影响当前宠物。「恢复默认（第 3 次）」只恢复点击次数，不重置其他偏好。

可调节角色大小、音量、提示音、角色外观、隐藏设置按钮、完成提醒、桌面置顶及登录启动。语录每行一则，也支持权重。简体与繁体可独立选择。

Gemini 高清与旧皮肤使用各自匹配的笑脸；旧皮肤没有高清随机表情池。DS 可选补耳立绘、仓库原图、自动眨眼或固定表情。新电脑若要使用未补耳的八张仓库原图，可先从源码目录运行 `python3 script/install_local_artwork.py`，下载到本机 artwork 缓存；这只下载原图，不会调用生成服务或覆盖补耳图。缓存缺失时保留内置立绘回退。

## 支持范围

本版在 Codex、本机 Antigravity 2.29.0、Claude 桌面版与 DeepSeek Harness 0.2.1-rc.5 的数据结构上开发。宿主升级后如缺少数据，会显示不可用，不生成虚假数值。

Claude 未接入额度，也不需要登录 Cookie。只有桌面版创建的 Code 对话可读取本地 token 计数；普通 Chat / Cowork 不在当前统计范围。

DS 原生余额服务需要[桥接配置](../integrations/README.md)。桥接仅输出币种、余额、账号散列与时间，凭据仍留在 Harness。更改桥接配置后请在自己的任务空闲时手动重开 Harness。

## TPS 统计

- GPT：完整完成轮次的输出 tokens（含思考）÷整轮耗时，包含工具、网络和确认等待。
- Gemini：宿主最新一次模型生成的输出 tokens（含思考）÷首 token 等待与生成耗时。
- Claude Code：本地 transcript 的整轮输出÷耗时。
- DS：本地 Harness 日志中完成轮次的输出÷耗时，终止或错误轮次不混入完成平均。

分模型最近平均使用加权口径：本组输出总量÷耗时总量。计数缺失或重置时显示不可用。没有自动调用模型的测速功能。

DS 费用估算采用代码中注明核对日期的价格表；实际费用以官方账单为准。今日余额消耗标注观测边界，离线、连接前与跨日缺口不声称完整覆盖。未知模型、未知日期价格和未知 token 计数均保留为未知。

## 找不到宠物

1. 确认 Node.js 20+ 已安装，宿主已打开且有可见窗口。
2. 从 Finder → 应用程序手动打开 `GPTNiangMac.app` 一次。
3. 如果宿主最小化或隐藏，跟随模式的宠物也会隐藏。桌面模式可以独立显示。
4. 不要同时运行旧版本与新版本；应用会通过锁防止重复实例。
5. 仍有问题时在 Issue 中提供 macOS / 宿主版本和脱敏截图，请勿粘贴登录信息或完整聊天记录。

## 数据、迁移与卸载

数据目录为 `~/Library/Application Support/AIQuotaCompanion/`，包含 `gpt`、`gemini`、`claude`、`deepseek` 与共享 `artwork` 缓存。更新应用不覆盖自定义语录或声音。

初次从上游 GPT 娘迁移时，程序会在没有 GPT 资料目录的情况下复制旧 `GPTNiangUsage` 中的设置和语录；不会删除旧数据。应用与登录助手继续使用原有 bundle 标识，以兼容现有安装，请勿同时运行两套。

手动更新：退出挂件 → 原位替换应用 → 从 Finder 打开。没有自动更新模块。

卸载：先关闭登录启动，退出挂件，移除应用。DS 如配置过桥接，仅删除自己的 `aiquota-companion` 插入项与模块，保留其他插件。数据目录可自行备份后决定是否删除；不需要清理任何宿主的账号或聊天资料。
