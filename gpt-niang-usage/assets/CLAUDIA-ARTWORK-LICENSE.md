# Claudia（小克）角色立绘许可与来源说明 · CC BY-NC-SA 4.0

本目录 `claudia/` 下的 16 张透明 PNG 素材（`idle`、`clawd`、`proud`、`sorry`、`asking`、`reading`、`listening`、`forgiven`、`redhot`、`puffed`、`sulk`、`coaxed`、`tired`、`oops`、`annoyed`、`dizzy`）源自开源非官方同人项目：

- **上游仓库**：[kirito1207/claudia-pet](https://github.com/kirito1207/claudia-pet)（`characters/claude/` 与 `archive/旧立绘-已被动画替换-不再使用/`）
- **角色底图与设定来源**：[lokicorvus/crosspet](https://github.com/lokicorvus/crosspet)（CrossPet 社区流行的 Claude 娘设定：铜橙色长发、橙花黑丝带金珠流苏发饰、维多利亚风格黑橙白书卷洋装与书 / Clawd 抱枕）
- **本机适配处理**：仅将原 WebP 透明图按等比底部对齐规范为 `640 × 640` 透明 PNG 画布，以便在 macOS 桌宠挂件内切换表情时保持脚底对齐无跳动。
